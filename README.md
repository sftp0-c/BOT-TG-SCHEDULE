# TG-бот расписания 25-28 (набросок)

Независимый проект (не часть `BOT-LPC`). Назначение: по команде в Telegram
присылать расписание группы **25-28** картинкой: бот находит актуальный PDF
колледжа, вырезает колонку группы на нужный день и присылает её.

> Статус: работает на живом сайте. Полный конвейер (поиск файла → PDF →
> вырезка дня и группы → картинка с шапкой дня и номерами пар) проверен
> и на архивных образцах (`samples/schedules`), и на живом файле
> `25-27-25-31 1.pdf` с collegelan.ru.

## Команды

- `/расписание` или `!расписание` — на день; после **13:00 по Екб**
  автоматически «завтра».
- `завтра` / `сегодня` — явно указать день.
- `21.10` или `21.10.2026` — на конкретную дату (удобно проверять на архивном
  PDF, где неделя 19–23.10.2026).
- `неделя` или `все` — колонка группы на все дни недели, что есть в файле
  (несколько картинок одним альбомом).

## Тест без сайта (SCHEDULE_LOCAL_PDF)

Сейчас тестовый режим **выключен** — бот берёт PDF с живого сайта. Источник ищется
по цепочке (каждый следующий шаг — только если предыдущий не дал файл):

1. страницы из `SCHEDULE_PAGE_URL` (можно список через запятую): бот каждый раз
   ищет там файл с шаблоном `25-27-25-31` (или диапазон, накрывающий 25-28) —
   имя файла периодически меняется («25-27-25-31.pdf» → «25-27-25-31 1.pdf»),
   актуальное всегда на странице. Структура HTML не важна: вытаскиваются все
   `href="*.pdf"` подряд;
2. если сам php переименовали/перенесли — бот открывает раздел
   `SCHEDULE_MENU_URL`, находит в меню ссылку «Расписание занятий» и проверяет её;
3. запасной вариант: прямая ссылка `SCHEDULE_DIRECT_URL` и её варианты
   («изм», «(изм)» и т.п.).

Проверить конвейер без сети можно, включив в `.env` локальный PDF:

```ini
SCHEDULE_LOCAL_PDF=C:\BOT-TG-SCHEDULE\samples\schedules\25-27-25-31_00e8da94d0354de8.pdf
TARGET_GROUP=25-28
```

## Структура

- `bot.py` — Telegram-бот (aiogram 3, polling), сборка ответа и отправка.
- `config.py` — настройки из `.env` с горячей перезагрузкой (`reload()`).
- `clock.py` — время Екатеринбурга, правило «после 13:00 → следующий день».
- `commands.py` — разбор команд (`сегодня/завтра/неделя/21.10`).
- `schedule_source.py` — источник PDF: локальный файл (тест), страницы из
  `SCHEDULE_PAGE_URL` (список через запятую), автопоиск страницы расписания по
  меню раздела, прямые варианты ссылки с пометкой «изм»; поиск по шаблону группы.
- `schedule_render.py` — PDF → картинки: страница = день, дата из шапки,
  вырезка блока группы по границам таблицы (не «на глаз»), проверка даты.
- `samples/` — образцы PDF колледжа для офлайн-тестов.
- `analysis/` — разовые скрипты разбора структуры PDF (не продукт).

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate   # Windows
pip install -r requirements.txt
# создать .env по разделу выше: TG_BOT_TOKEN, ссылки, группа
python bot.py
```

## Зависимости

- `aiogram` — Telegram Bot API.
- `pymupdf` — рендер PDF в картинки.
- `Pillow` — склейка шапки дня, полосы «№» и колонки группы.
- `httpx` — HTTP (страница расписание / PDF / проверки).
- `python-dotenv`, `tzdata` — настройки и часовой пояс Windows.
